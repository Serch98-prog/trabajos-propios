# Trabajos Propios de Python

Repositorio donde guardo los proyectos que desarrollo mientras aprendo programación con Python.

## Habilidades desarrolladas

- Variables
- Condicionales (if, elif, else)
- Entrada y salida de datos
- Operadores matemáticos
- Validación básica de datos
- Funciones (def)
- Listas
- Diccionarios
- Bucles (for y while)
- Manejo de archivos TXT
- Manejo básico de excepciones (try/except)

## Proyectos

### Gestor de tareas
Permite agregar, visualizar y administrar tareas mediante un menú interactivo.

### Lista de contactos
Permite agregar, buscar, editar y eliminar contactos. Incluye almacenamiento de información en archivos TXT.

### Sistema de inventario
Administra productos mediante operaciones de alta, búsqueda, actualización y eliminación. Permite guardar y cargar datos desde archivos TXT y calcular el valor total del inventario.
